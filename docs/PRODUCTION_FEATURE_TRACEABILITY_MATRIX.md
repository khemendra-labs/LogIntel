## 1. Classification & Verification Standards

### 1.1 Primary Completeness Status (Phase F)
Each feature is assigned exactly one primary completeness status:
- **`IMPLEMENTED_AND_INTEGRATED`**: Feature has a discoverable UI entry point, working API client, authenticated backend handler, persistent DB storage, and full verification evidence.
- **`IMPLEMENTED_BUT_UNREACHABLE`**: Fully implemented in source code and backend, but missing a reachable navigation path in the desktop UI.
- **`IMPLEMENTED_BUT_DISCONNECTED`**: UI component and backend exist, but the API client helper is missing, mocked, or misconfigured.
- **`PARTIALLY_IMPLEMENTED`**: Feature is split across components with missing workflow glue or incomplete state synchronization.
- **`BACKEND_ONLY`**: Backend route and service are functional, but no frontend component exists to expose it.
- **`FRONTEND_ONLY`**: React component exists, but the backend endpoint or persistence layer is unimplemented.
- **`BLOCKED_BY_DATA_OR_CONFIGURATION`**: Feature is functional, but unusable due to missing telemetry data or environment configuration.
- **`PRESENT_IN_SOURCE_BUT_ABSENT_FROM_INSTALLED_BUILD`**: Implemented and integrated in the current repository working tree, but absent from the older installed binary currently on `/usr/bin/logintel-bin`.
- **`NOT_IMPLEMENTED`**: Requirement defined in milestone documentation, but code is absent from the repository.
- **`UNVERIFIED`**: Feature exists, but has not been exercised by automated tests or live runtime checks.

### 1.2 Independent Verification Levels
Multiple verification levels apply to each feature:
- `SOURCE_INSPECTED`: Exact source files, routes, and components reviewed and confirmed.
- `AUTOMATED_TESTED`: Covered by passing unit or integration tests in Vitest or Pytest.
- `API_INTEGRATION_TESTED`: Live HTTP requests verified against running backend engine on port 41721.
- `INTERACTIVELY_VERIFIED`: Rendered and tested within the desktop UI.
- `INSTALLED_PACKAGE_VERIFIED`: Verified inside the installed `.deb` package payload.
