## 2. Milestone Architecture & Detailed Implementation

### 2.1 Backend Architecture

#### 2.1.1 Data Models (`apps/engine/src/logintel/multihost/models.py`)
- **`MultiHostExportResponse`**: Standardized model for export payloads:
  - `case_id: int` — Authoritative investigation case identifier.
  - `format: str` — Export format indicator (`"json"` or `"markdown"`).
  - `filename: str` — Standardized export filename (`case_{case_id}_multihost_dossier.json` or `case_{case_id}_multihost_report.md`).
  - `content: str` — Serialized dossier JSON or structured Markdown document.
  - `root_digest: str` — Cryptographic SHA-256 provenance fingerprint (`sha256:...`) ensuring report integrity and chain of custody.

#### 2.1.2 Service Layer (`apps/engine/src/logintel/multihost/service.py`)
- **`export_dossier(case_id: int, format: str = "json") -> MultiHostExportResponse`**:
  - Fetches the authoritative `CaseMultiHostDossier` via `get_case_dossier(case_id)`.
  - Validates requested export format (`json` or `markdown`), raising a `ValueError` for unsupported types.
  - For JSON: serializes the complete dossier with indented formatting and deterministic key ordering.
  - For Markdown: formats a complete forensic incident report containing:
    1. Header with case ID, timestamp, scope mode, and provenance fingerprint.
    2. Executive Summary with participating host counts, hop totals, entity continuities, and visibility gap counts.
    3. Participating Host Catalog & Epistemic Status table detailing OS, observed status (`OBSERVED` vs `UNKNOWN`), event/alert counts, inbound/outbound hops, and gaps.
    4. Reconstructed Lateral Movement Traces table detailing source, target, actor, hops, status, and time windows.
    5. Cross-Host Entity Continuity table detailing shared user accounts and IP addresses across machines.
    6. Visibility Boundaries & Completeness Limitations section detailing collection gaps and epistemic limitations.
    7. Footer certifying deterministic compilation by the LogIntel Multi-Host Investigation Engine with the root digest.

#### 2.1.3 API Routes (`apps/engine/src/logintel/api/routes.py`)
- **`GET /api/v1/cases/{case_id}/hosts/export`**:
  - Registered on `@protected_router` with Bearer token authentication enforcement.
  - Query parameter `format`: validated via regex `^(json|markdown)$` with default `"json"`.
  - Non-existent cases return `404 Not Found`.
  - Invalid formats return `422 Unprocessable Entity`.
  - Unauthenticated requests return `401 Unauthorized`.
