## 1. Security Architecture & Threat Model

Milestone M7.4 implements analytical reasoning workspaces where analysts formulate findings, attach evidence, and evaluate hypotheses. In accordance with LogIntel's forensic trust model:

1. **Authentication & Authorization Boundary:**
   - Every findings and hypothesis endpoint requires valid bearer token authentication.
   - Non-existent cases return 404; missing authentication returns 401; invalid tokens return 401.
2. **Strict Case Isolation:**
   - Findings and hypotheses created in Case A are strictly invisible and inaccessible from Case B.
   - Cross-case evidence references (e.g. attempting to attach evidence belonging to Case B into a finding in Case A) are rejected.
3. **Evidence Immutability Guarantee:**
   - Deleting a finding or hypothesis never deletes underlying evidence references in `cases.db` or raw telemetry events in `logintel.db`.
   - Removing evidence from a finding disassociates only the finding link.
4. **Epistemic State Invariance:**
   - Reviewing an inferred finding as `ACCEPTED` does not convert its epistemic status to `OBSERVED`.
   - The system forbids silent promotion of inferences or hypotheses into facts.
5. **Adversarial Input Handling:**
   - SQL injection strings, shell syntax, script tags, Unicode homoglyphs, and prompt injections are treated strictly as inert data without execution.
6. **AI Advisory Boundary:**
   - Automated AI advice cannot mutate authoritative finding states, accept hypotheses, alter epistemic statuses, or execute commands.
