## 8. Documented Limitations

1. **In-Memory Attack Sequence Synthesis:** Attack sequences and threat assessments are evaluated on-demand in unprivileged memory rather than stored in a separate database table. This guarantees zero schema drift while providing sub-millisecond evaluation latency for active incident windows.
2. **Deterministic Heuristic Mapping:** Threat stages rely on canonical event type matching and bounded regex heuristics rather than probabilistic or opaque ML models, preserving deterministic explainability.
