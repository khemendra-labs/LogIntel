## 2. Epistemic Baseline & Core Invariant

The validation harness rigorously respects epistemic certainty boundaries:
1. **Fact vs Inference:** Events ingested are recorded as `OBSERVED`. Multi-stage campaign sequences inferred by correlation algorithms are attributed as `INFERRED` with quantitative confidence ($0.0 \le \text{confidence} \le 1.0$).
2. **Missing Stages as Gaps:** If an adversary stage has no supporting telemetry, the sequence engine records an evidence gap rather than fabricating hypothetical links.
3. **Zero Host Mutation:** Host readiness inspections execute in user memory using non-destructive, read-only file queries and `/proc` probes. Adversary scenarios are synthesized entirely in memory as canonical event streams, ensuring zero side-effects or state modification on the live host.
