### 1. Gap Analysis

| Requirement Area | Existing M5.3 Primitives | M5.4 Gap / Delta | Implementation Strategy |
|---|---|---|---|
| **Investigation Lifecycle** | Incident status (`OPEN`, `TRIAGED`, `INVESTIGATING`, etc.) | Analyst workspace state machine (`OPEN`, `ACTIVE`, `PAUSED`, `READY_FOR_REVIEW`, `CLOSED`) with strict validation | Implement `InvestigationState` and transition audit trail in `workspace_service.py` |
| **Investigation Scope** | Unbounded incident-level queries | Reproducible scope: `time_start`, `time_end`, `subject_type`, `subject_id`, `selected_entity_ids`, etc. | Model `InvestigationScope` referencing authoritative IDs |
| **Evidence Workbench** | Multi-dimensional `InvestigationEvidenceBundle` with 7 entity types | Evidence candidate collection from approved queries, explicit provenance display | Add `evidence_candidates` tracking and provenance inspection |
| **Hypothesis Workflow** | AI-generated `Hypothesis` structures | Analyst-owned lifecycle: `OPEN`, `SUPPORTED`, `WEAKENED`, `UNRESOLVED`, `REJECTED` | Model `AnalystHypothesis` with supporting/contradicting evidence links and analyst assessments |
| **Explainability Layer** | `AIClaim` epistemic validation | Interactive claim-to-citation-to-source provenance tracer | Implement `/explainability` endpoint tracing `claim → citations → evidence → raw source` |
| **Query Approval Workflow** | `preview_query_proposal` (read-only) | Approved query execution converting results into evidence candidates | Add `/query/execute` endpoint for analyst-approved execution without raw SQL |
| **Evidence Gaps** | `EvidenceGap` (`VISIBILITY_GAP` vs `OBSERVED_ABSENCE`) | Extended gap categorization: `NO_EVIDENCE_FOUND`, `TELEMETRY_GAP`, `OUTSIDE_SCOPE`, `INSUFFICIENT_CONTEXT` | Codify gap classification in bundle and summary models |
| **Investigation Summary** | Markdown dossier export | Deterministic structured multi-section summary schema | Implement `generate_investigation_summary` covering all 17 specified sections |
| **Report Drafting** | Non-structured narrative text | Structured report draft separating `FACT`, `INFERENCE`, `HYPOTHESIS`, `UNKNOWN` | Implement `generate_report_draft` with mandatory citation grounding |
| **Analyst Notes Integration** | M4 `investigation_notes` CRUD | Explicit boundary: `ANALYST NOTE` vs `AI DRAFT` vs `AUTHORITATIVE EVIDENCE` | Provide workflow to promote AI draft to persistent analyst note |
| **Database Preservation** | 8 canonical tables, 141,913 records | Zero schema mutations (No Migration 6) | Store workspace state in service registry without touching baseline SQLite tables |
