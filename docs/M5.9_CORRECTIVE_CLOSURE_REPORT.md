# 3. C01 — CONFIDENCE TERMINOLOGY RECONCILIATION

### Analysis & Resolution:
1. **Field Inspection:** The M5.9 domain model previously declared `confidence_basis` on `CorrelationReasonItem`. While this field was explanatory rather than numerical (e.g. `"Deterministic attribute equality"`, `"Corroboration: CORROBORATED"`), the word `confidence` could be misinterpreted as a probabilistic score.
2. **Semantic Refactoring:**
   - In `apps/engine/src/logintel/ai/domain/investigation_correlation.py`: Renamed `confidence_basis` to `correlation_basis: str = "Deterministic attribute equality"`.
   - In `apps/desktop/src/types/investigation.ts`: Updated `CorrelationReasonItem` interface to expose `correlation_basis: string`.
   - In `apps/desktop/src/features/InvestigationCorrelationExplorer.tsx`: Rendered `{r.correlation_basis}` instead of `{r.confidence_basis}`.
   - In `apps/engine/tests/test_ai_intelligence_m59.py`: Asserted `assert r.correlation_basis != ""`.
   - In `apps/desktop/src/__tests__/api.test.ts`: Updated test mocks to use `correlation_basis: "Exact entity equality"`.
3. **Database Field Distinction:** The column `confidence` in `incident_relationships` (`DIRECT`, `STRONG`, `CORRELATED`) is an authoritative schema column from M4 and remains unmodified.
4. **Epistemic Separation Preserved:** Strict separation is maintained between:
   - `epistemic_status`: `OBSERVED`, `INFERRED`, `UNKNOWN`
   - `correlation_reason`: deterministic enum (`SHARED_ENTITY`, `SHARED_SESSION`, `TEMPORAL_PROXIMITY`, etc.)
   - `correlation_basis`: factual explanation of equality or proximity
   - `corroboration_status`: `CORROBORATED`, `UNCONTRADICTED`, `CONTRADICTED`, `INSUFFICIENT_EVIDENCE`

# 7. C05 — SHA-256 PROVENANCE LANGUAGE

All evidence references and cluster citations expose 64-character hexadecimal SHA-256 digests generated and validated by the provenance mechanism:
- **Algorithm:** Standard `SHA-256` (`hashlib.sha256`).
- **Input:** Canonical forensic payload representation (`f"{source_table}:{source_id}:{timestamp}:{raw_content}"`).
- **Validation:** String length verified to be exactly 64 characters, prefixed with `sha256:`, conforming to lowercase hexadecimal charset `[0-9a-f]{64}`.
- **Boundary:** Provenance digests represent deterministic content fingerprints generated by the ingestion and retrieval layers; they are not claimed as external third-party digital notary certificates.
