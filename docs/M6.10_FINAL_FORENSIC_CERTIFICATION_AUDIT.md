## 5. Functional Area Audits (M6.1 through M6.10)

### M6.1: Architecture & Telemetry Readiness
* Verified readiness of unprivileged Linux host telemetry pipelines.
* Strict enforcement of forensic immutability, epistemic certainty governance (`OBSERVED`, `INFERRED`, `UNKNOWN`), and zero external cloud network dependency.
* Verified loopback isolation (`127.0.0.1`, `localhost`) for all telemetry and AI endpoints.

### M6.2: Process & Execution Telemetry via `auditd`
* **Audit Source:** `/var/log/audit/audit.log` is readable unprivileged via membership in group `adm`.
* **Kernel Rule Prerequisite:** Querying `type=EXECVE` on the default live host returns 0 records because the kernel rule `-S execve` is not loaded.
  * `AUDIT SOURCE AVAILABLE`: **True**
  * `EXECUTION RULE CONFIGURED`: **NOT CONFIGURED**
  * `Critical Epistemic Distinction:` `EXECVE NOT OBSERVED` is classified as `UNKNOWN / RULE_NOT_CONFIGURED`, never as "absence of process execution."
* **Process Identity:** Derived via `build_process_identity` in `ancestry.py` as `proc:host:pid:timestamp_iso:executable:seq{audit_seq}`. Certified as a **deterministic collision-resistant process identity token under the tested identity inputs**.
* **Process Ancestry:** `ProcessAncestryResolver` reconstructs parent-child execution hierarchies with cycle detection and depth clamping (32 generations). Missing PPID or PPID=0 is classified as `UNKNOWN`, never manufactured as `SPAWNED`.
* **Raw Evidence Fidelity:** Byte-for-byte preservation in `raw_message` verified via `test_m62_sec_009_raw_evidence_fidelity`. Masking applies strictly to canonical fields (`command_line`, `summary`) and AI context serializers. Classified as a sensitive forensic boundary.

### M6.3: Advanced Identity, Session Continuity & Privilege
* **AUID Continuity:** Tracks login user identity (`AUID` / `audit_session_id`) across privilege elevations (`UID` $\rightarrow$ `EUID`). When `AUID=4294967295` (unset), the actor is represented as a system daemon without fabricating human identity.
* **Privilege Elevation Parsers:** `SudoCommandParser`, `SudoFailureParser`, `PAMParser`, and `SSHSuccessParser` track credentials, privilege transitions, and session lifecycles.
* Credential masking deterministically redacts passwords and auth tokens in canonical outputs while raw text is preserved in `raw_message`.

### M6.4: Linux Network & Socket State Telemetry via Procfs
* **Socket Table Reading:** `ProcNetReader` decodes `/proc/net/tcp` and `/proc/net/tcp6` tables with deterministic IPv4/IPv6 address hex parsing.
* **Process Correlation:** `SocketProcessResolver` matches active socket inodes against `/proc/<pid>/fd/`. On the live host, 55 sockets resolved to observed processes; 17 unmapped sockets (root/kernel owned) were marked `UNKNOWN`.
* **Documented Limitation — Transient Sockets:** Procfs polling cannot guarantee observation of short-lived sockets that open and terminate between polling intervals. Full packet-level or complete socket lifecycle telemetry is not claimed; eBPF socket monitoring is not implemented in M6.

### M6.5: Filesystem & Persistence Telemetry (HVT Monitoring)
* **High-Value Target (HVT) Monitoring:** `FileIntegrityScanner` monitors sensitive persistence locations (`/etc/cron.*`, `/etc/systemd/system`, `/etc/pam.d`, `~/.ssh/authorized_keys`).
* **Epistemic Classification:**
  * `FILE AVAILABLE`: Path exists and is accessible.
  * `FILE SCANNED`: Metadata recorded and SHA-256 hash computed.
  * `FILE CLAMPED`: Files exceeding `max_hash_size_bytes` (10 MB) receive `epistemic_status = "SIZE_EXCEEDED"` with `sha256_hash = None` without reading into memory (`test_m65_sec_003_large_file_size_clamping`).
  * `FILE UNAVAILABLE`: Path missing or unreadable (`PERMISSION_RESTRICTED`, e.g. `/etc/shadow`).
* **Traversal & Symlink Defense:** Symlink loops and path traversal attacks (`../`) resolve safely to canonical paths. Disposable temporary fixtures used exclusively.

### M6.6: Systemd Unit Lifecycle & Security Kernel Telemetry
* **Systemd Inspection:** `SystemdUnitTracker` queries service lifecycles via `systemctl list-units` with graceful unprivileged fallback, detecting restart loops and failure cascades.
* **Kernel Telemetry:** `KernelCollector` deterministically parses module loads (`sys_module`), out-of-tree taint flags, signature verification failures, and promiscuous mode transitions from `/dev/kmsg` or syslog.
* **AppArmor Denials:** AVC denial records extract profile names, operations (`symlink`, `open`), requested masks, and target paths into structured canonical security denial events. `OBSERVED` state is assigned strictly when actual records are observed.

### M6.7: Container & Namespace Telemetry
* **Namespace Profiling:** `NamespaceInspector` establishes baseline host namespace inodes from `/proc/1/ns/` (8 namespaces: `mnt`, `net`, `pid`, `ipc`, `uts`, `user`, `cgroup`, `time`). Namespace divergence in child processes indicates containerized execution unprivileged.
* **Docker Socket Limitation:** Access to `/var/run/docker.sock` is restricted to root and group `docker`. When accessed unprivileged, LogIntel degrades gracefully, reporting `CONTAINER_TELEMETRY_UNAVAILABLE`. This condition must NOT be interpreted as "no containers exist" or "containers are safe."

### M6.8: Unified Linux Host Graph & Causal Schema Reconciliation
* **In-Memory Causal Synthesis:** `HostGraphBuilder` synthesizes host causal graphs dynamically in unprivileged memory. Nodes and edges carry explicit event IDs (`evidence_event_ids`) and discrete epistemic statuses (`OBSERVED`, `INFERRED`, `UNKNOWN`).
* **Migration 6 Reconciliation:**
  > **M6.8 did not introduce a persistent schema migration. Host graph intelligence is synthesized on demand from existing canonical telemetry structures; therefore the M6 program does not require Migration 6.**
  The database invariant `len(MIGRATIONS) == 5` is strictly preserved.

### M6.9: Advanced Detection & Threat Correlation on Host Telemetry
* **Host Rules Catalog:** All 18 specialized host detection rules verified from source (`rules/security/`, `rules/process/`, `rules/privilege/`, `rules/network/`, `rules/authentication/`).
* **Deterministic Attack Sequences:** `HostThreatCorrelator` reconstructs multi-stage attack sequences across MITRE ATT&CK tactics without non-deterministic graph exploration or arbitrary execution.
* **Scoring Semantics:** Scores (e.g. 90.0, 100.0, 70.0) represent:
