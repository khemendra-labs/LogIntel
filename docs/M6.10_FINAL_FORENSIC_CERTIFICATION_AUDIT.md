## 28. Documented Limitations

The following limitations are explicitly recognized, documented, and accepted as part of this certification:
1. **Host Audit Rule Prerequisite:** Capturing process executions via `auditd` requires kernel audit rules (e.g. `auditctl -a always,exit -F arch=b64 -S execve`). Without this rule, `auditd` emits other records but not `EXECVE`; LogIntel properly flags missing telemetry.
2. **Unprivileged Docker Socket Access:** The unprivileged engine process cannot access `/var/run/docker.sock` without elevated permissions; the system degrades gracefully to `CONTAINER_TELEMETRY_UNAVAILABLE`.
3. **Transient Network Sockets:** Procfs polling cannot observe ephemeral TCP sockets that open and terminate between polling intervals; full socket tracing requires future eBPF instrumentation.
4. **Interactive Desktop UI:** The desktop frontend was verified via automated Vitest API suites (46/46) and production TypeScript compilation; interactive browser UI sessions were not executed.
5. **Historical Baseline Dataset:** Row-level historical preservation proofs are not executable due to absence of an authoritative historical baseline database dump (`HISTORICAL RECONCILIATION NOT EXECUTABLE — DATASET UNAVAILABLE`).
6. **Debian Package Build Date:** The existing `.deb` package was compiled at M2.11 and has not been rebuilt for M6; clean-machine package installation was not re-executed during this audit.
