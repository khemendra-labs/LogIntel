## 40. Known Limitations

The following limitations are explicitly documented and accepted:
1. **Host Audit Rule Requirement:** Ingestion of process executions via `auditd` requires kernel audit rules (e.g. `-a always,exit -F arch=b64 -S execve`). Without rules, auditd does not emit events; LogIntel correctly classifies this as `RECORD_NOT_AVAILABLE`.
2. **Unprivileged Docker Socket Access:** The unprivileged test user lacks access to `/var/run/docker.sock`, which LogIntel handles cleanly via graceful fallback to `CONTAINER_TELEMETRY_UNAVAILABLE`.
3. **Transient Network Sockets:** Short-lived TCP connections that close before the procfs poll interval are not captured; full socket connection tracing requires future eBPF socket lifecycle probes.
4. **Interactive Browser UI:** Desktop frontend verified via automated Vitest suites and TypeScript compilation; live interactive browser validation was not executed.
5. **Historical Baseline Dataset:** Row-level historical preservation proofs are not executable due to absence of an authoritative historical baseline database dump.
