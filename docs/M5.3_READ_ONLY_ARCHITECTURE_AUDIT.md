## 1. EXECUTIVE SUMMARY & AUDIT PURPOSE

The fundamental architectural invariant governing M5.3 remains absolute:
```text
AI may interpret authoritative evidence, but AI must never become authoritative evidence.
```

The M5.2 milestone achieved formal closure at commit `268849dbce0c8fe439366df6554b5dfd974df83c`, having established:
1. Local-only loopback AI runtime boundary (Ollama v0.35.0, `127.0.0.1:11434`, zero external network dependencies).

* Evidence conflict detection and visibility gap disclosure.
* Structured investigation intents (`SUMMARY`, `TIMELINE`, `ENTITY_ANALYSIS`, `ALERT_EXPLANATION`, `HYPOTHESIS`, `EVIDENCE_GAP`, `NEXT_QUERY`).

## 10. ARCHITECTURAL ANALYSIS: FOUNDATIONS FOR M5.3

M5.3 introduces the **evidence synthesis and investigation intelligence layer**. The audit reveals that the foundational primitives already exist and can be cleanly extended:

1. **Evidence Bundle Abstraction:**
   * M5.1 created `InvestigationContext` which holds events, alerts, detections, entities, relationships, MITRE mappings, and notes.
   * M5.3 requires an `InvestigationEvidenceBundle` that enriches these items with explicit **roles** (`PRIMARY`, `SUPPORTING`, `CONTEXTUAL`, `CORROBORATING`, `CONTRADICTING`, `TEMPORAL`, `ENTITY_LINK`) and provenance pointers, while keeping the data read-only.
2. **Deterministic Evidence Retrieval:**
   * `investigation_repo.py` already implements deterministic queries for attack paths, entity pivots, event forensics, and timeline items.
   * M5.3 can introduce a dedicated `EvidenceRetriever` that coordinates retrieval across the 7 entity types, temporal intervals (before/during/after), corroboration groups, and conflict checks.
3. **Evidence Gaps & Conflict Representation:**
   * M5.1 tracked `truncation` (budget omissions).
   * M5.3 requires formal structures for `EvidenceGap` (e.g. missing auditd telemetry, missing process logs) and `EvidenceConflict` (e.g. login success vs disabled account, conflicting timestamps).
4. **Structured Investigation Intent Pipeline:**
   * M5.2 accepted a generic `task: Optional[str]`.
   * M5.3 introduces structured investigation intents (`SUMMARY`, `TIMELINE`, `ENTITY_ANALYSIS`, `ALERT_EXPLANATION`, `DETECTION_EXPLANATION`, `ATTACK_PATH_EXPLANATION`, `MITRE_EXPLANATION`, `HYPOTHESIS`, `EVIDENCE_GAP`, `NEXT_QUERY`) with a deterministic `QuestionClassifier`.
5. **Safe Query Proposal:**
   * AI may suggest next hunting queries as structured `QueryProposal` objects (filters, entity, time range), but the AI will **never** generate or execute raw SQL.
6. **Token Budget Preservation:**
   * M5.2 confirmed: `num_ctx = 2048`, `reserved output = 512`, `effective input budget = 1536 tokens`.
   * M5.3 will use relevance scoring and context deduplication to select high-priority evidence without exceeding the 1,536 token effective ceiling.
